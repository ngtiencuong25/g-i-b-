# Gửi Bố ❤️

Một trang web/thiệp điện tử nhỏ để gửi bố.

## Chạy trên máy
Mở `index.html` trực tiếp, hoặc dùng VS Code + Live Server.

## Deploy GitHub Pages
1. Tạo repository mới.
2. Upload `index.html`, `style.css`, `script.js`.
3. Vào Settings → Pages.
4. Chọn Deploy from a branch → `main` → `/root`.
5. Lưu và chờ GitHub Pages build.

## Tùy chỉnh
- Sửa nội dung lá thư trong `index.html`.
- Đổi giao diện trong `style.css`.
- Đổi hiệu ứng trong `script.js`.
